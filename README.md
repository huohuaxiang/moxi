# 墨戏 · 打字成墨，落笔生万象

一个单文件网页应用：移动鼠标选位置，写下汉字，字会以真墨的形式落进纸里，随后化成对应的物象（山、竹、鱼、月……）。天气与物象互相影响，笔迹是实时流体。

## 怎么跑

直接双击 `墨戏.html`（或拖进浏览器）。不需要服务器、不联网、不装任何东西。
需要浏览器支持 WebGL2（Chrome / Edge / Firefox 近几年的版本都行）。

也可以直接打开 `index.html`（多文件版，依赖 css/ 与 js/）。

移动端同一个页面也能开：点下方的字牌落墨，或在输入框里打字。

## 操作

| 动作 | 效果 |
|---|---|
| 移动鼠标 | 决定下一个字落在哪里（笔位圈会跟着走） |
| 在底部输入框打字 + 回车 | 落字成墨，并化成物象 |
| 点下方的字牌 | 同上，按预设位置轮转 |
| 按住鼠标拖动 | 像毛笔一样拖出墨线，墨会被速度场推着走 |
| 洗 | 清空纸面与墨 |
| 聲 | 开关声音（拨弦、风雨、雷、洗纸） |

字库：雨、风、雪、云、雾、雷 / 山、水、石、月 / 竹、松、梅、柳、荷、菊、兰 / 鱼、鹤、鸟、蝶 / 舟、亭、灯、印、墨。

规则联动（落墨时会提示）：风起竹摇、雪落松枝、鱼戏荷叶、鹤伴月、舟行水面、雾锁山头、月照山、雷震墨散……

```

js/entities.js     20+ 物象与雨雪风雾雷的画法
js/world.js        实体池、落字位置、天气统计、规则提示、洗纸

js/audio.js        五声音阶拨弦、风雨雷、笔触噪声
```

## 原理（四层）

1. **墨是流体**：GPU 上的稳定流体（Stable Fluids），速度场与墨浓度都是浮点纹理，涡量增强 + 压力投影保证不可压，半拉格朗日平流把墨带着走。鼠标拖拽会往速度场里注入冲量，所以墨会被拖着跑。
2. **字是墨模**：把汉字画进 512 的白字黑底画布，逐行错位模拟笔势，再用纸纤维纹理抠出飞白，最后按点按成一串墨点 stamp 进流体。字因此不是贴图，而是真的墨。
3. **物象是笔画的组合**：山是淡墨体 + 披麻皴 + 山脊线，竹是竿 + 节 + 叶（起笔宽收笔尖的叶片形），鱼是两笔成形的弧背。全部用同一套笔刷函数画出来，所以和字、和拖笔是同一种墨。
4. **天气是场**：雨/雪/雾是粒子，风是平滑噪声场并持续给流体加速，雷是低通噪声爆发。物象自己也在动（竹摇、水波、灯闪），彼此用简单规则互相触发。
